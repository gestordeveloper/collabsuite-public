Teste do script gerado pela aba "Widget de Chamados"

Esta página simula uma plataforma externa que colou o script embeddable. Ela usa os dados reais do projeto:

  • Projeto: Website - Ramos Medicina Diagnostica (id 3)
  • Funil: Funil Principal (funnel_id 3, padrão)
  • Usuário de teste (fictício): teste.widget@exemplo.com

Clique no botão flutuante no canto inferior direito para abrir um chamado. Ele vai cair na coluna BACKLOG do Kanban desse projeto — pode excluir o card de teste depois.

Atenção: abrir um chamado aqui cria de verdade um usuário e uma tarefa no seu banco de dados (email teste.widget@exemplo.com), dentro do projeto real acima. Não é um ambiente isolado — é o mesmo backend do CollabSuite rodando em localhost:3000.

Script embedado nesta página (o mesmo que a aba "Widget de Chamados" do projeto gera):

<script src="http://localhost:3000/api/public/widget/script.js"></script> <script> window.CollabSupportWidget.init({ funnel_id: 3, user_id: "test_ext_1", first_name: "Usuário", last_name: "Teste", email: "teste.widget@exemplo.com", telephone: "11999990000" }); </script>
